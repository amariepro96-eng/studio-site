MISE À JOUR STUDIO SITE — Mentions légales sans blocage
========================================================

Ce qui change
- Les mentions légales incomplètes (passages entre crochets) n'empêchent plus
  « Mettre en ligne » ni « Publier une nouvelle version ».
- Elles restent signalées en orange dans le bloc Mise en ligne, avec le bouton
  « Compléter le brief ».
- L'historique du dossier note « mentions légales incomplètes » à chaque
  version publiée ainsi.
- La case « Vérifier les mentions légales » de la liste Mise en service ne se
  coche plus toute seule tant qu'il reste des crochets.
- Les publications depuis l'espace client ne sont plus bloquées non plus.

Fichiers remplacés (5) : README.md, app/api/agence/clients/[id]/publication/route.js,
src/server/publish.js, src/ui/agency/Publication.jsx, src/ui/styles.css

Installation (document 10, §G)
1. Ouvre ton dépôt studio-site sur GitHub (ton compte personnel, pas Station-Site).
2. Add file › Upload files.
3. Ouvre le dossier studio-site-github, fais Ctrl + A (dossiers app, src et
   README.md) et glisse le tout dans la zone. Ne glisse PAS le dossier
   studio-site-github lui-même.
4. Message : « Mentions légales sans blocage » › Commit changes.
5. Attends « Ready » dans Vercel (projet studio-site-2), puis recharge l'espace
   agence avec Ctrl + F5.

Rappel : un site professionnel doit afficher des mentions légales complètes
(loi pour la confiance dans l'économie numérique). Complète-les avant de livrer
le site à un vrai client.
